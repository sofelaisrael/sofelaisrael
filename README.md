### 🧠 Sift

**Flutter · ML Kit · Gemini · CI/CD**

> **Screenshot → AI understands → Takes action**

Sift turns screenshots into useful actions such as calendar events, reminders, and shopping lists.

The interesting part isn't just the AI — it's the pipeline around **on-device OCR, structured extraction, action generation, and mobile UX**.

* On-device screenshot processing
* ML Kit OCR
* Gemini-powered understanding
* Automated testing and CI/CD

[Repository](https://github.com/sofelaisrael/sift)

---

### 🔍 Gitective

**Go · Git · CLI · Terminal UI**

> **Investigating your Git history**

Gitective treats Git history as behavioral data.

Instead of only showing what happened, it looks at things like commit timing, files changed, lines added or removed, and commit messages to generate personality-style reports.

`git log` tells you what happened.

**Gitective tries to tell you how you work.**

[Repository](https://github.com/sofelaisrael/gitective)

---

### ⚙️ TinyOps

**Next.js · TypeScript · MDX · Tailwind**

A curated library of **CI/CD prompts** for Vercel and GitHub Actions.

Developers can browse, search, customize, and copy prompts for generating deployment and automation workflows.

[Repository](https://github.com/sofelaisrael/TinyOps)
